Getting Started

New to FreehandNX? Start by creating your account on Sign Up, then open the editor and begin a new session.

  • Create a new project session
  • Choose your canvas/page size
  • Build with text, images, shapes, and grids
  • Export as HTML, PDF, or images

Core Workflow

FreehandNX is built around session-based projects. Each session keeps your pages, assets, and layout state together for a focused publication workflow.

Using AI Features

In the editor, AI tools are available directly in the left toolbar and image panels.

  • Raster Image: generate new images from text prompts
  • Image Edit: transform selected images with prompt-based edits
  • Vector Art: generate vector-style graphics and icon-like assets
  • Film Looks: apply visual styling with adjustable strength

Pages, Grids, and Typography

Use page presets and custom dimensions, then structure layouts with built-in and custom grid controls. Text tools support OpenType-style workflows for publication design.

  • Use portrait and landscape page presets
  • Enable and customize grids for precise alignment
  • Adjust typography directly from the inspector

Projects and Sessions

Open the Library from the left toolbar to manage your projects.

  • Enter a project name in the Library input
  • Click Save to store your current session state
  • Click the + icon to create a new project and start fresh
  • Open any project card to continue where you left off

Export

Use the export controls to output your work for production or sharing.

  • Export as HTML for interactive handoff
  • Export as PDF for print-ready delivery
  • Export as images for social and digital use

Order Publications

Ordering publications from FreehandNX is planned and currently marked as coming soon.

Credits & Billing Help

FreehandNX uses a subscription + credits model. An active subscription unlocks full access to the editor. Credits are used for AI actions.

If you need more credits, visit Pricing. For subscription, billing, or purchase issues, please reach out through Contact.

Performance Tips

  • Use a modern browser and keep it updated
  • Close unused tabs during heavy canvas work
  • Use stable internet for save and AI actions

Account & Access

Account access uses Google sign-in. If you can’t access your account, first retry from Sign Up, then contact us if the issue continues.
