FAQs

What is FreehandNX?

FreehandNX is a modern canvas-based design tool for posters, photobooks, magazines, and multi-page publication layouts with AI tools built in.

How is FreehandNX different from traditional editors?

FreehandNX is built around page layout and publication flow instead of catalog-based editing workflows. You can design directly on canvas with grids, text, masks, AI tools, and export-ready outputs.

Do I need to install anything?

No. FreehandNX runs in the browser, so you can start from the web app and work directly online.

How do credits work?

Credits are used for AI-powered actions such as image generation, image edits, and vector generation. Subscription and top-up details are available on the Pricing page.

Do credits expire?

No. Credits are pay-once and do not expire.

What file types can I work with?

FreehandNX supports common web image formats for import and placement, plus AI-generated assets in your design workflow.

Can I create multi-page projects?

Yes. FreehandNX is built for multi-page publication work with page management and session-based project organization.

What AI features are available?

FreehandNX includes Image Generation, Image Edit, and Vector Art generation. Film Looks are also available for quick visual styling.

Can I still design manually, or is it only AI?

You can do both. Manual design controls and AI tools are designed to work together in the same canvas workflow.

What export formats are supported?

You can export projects as HTML, PDF, and images depending on your workflow and delivery needs.

Can I use FreehandNX for client/commercial work?

Yes. FreehandNX is built for production workflows. Always review final outputs for client, legal, and brand requirements before delivery.

Can I order printed publications from FreehandNX?

Ordering publications is planned and currently marked as coming soon.
